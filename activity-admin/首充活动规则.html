新用户首充200%赠金活动规则

一　活动信息

  1. 活动对象：符合平台新用户及首充资格的用户，每位用户仅可参与一次。
  2. 活动周期：以活动页面公布的开始时间、结束时间为准。
  3. 参与门槛：首次成功入金起24小时内累计有效入金达到100 USD，并在窗口结束后完成定档。达到门槛不代表立即发放返佣。
  4. 活动品种：仅限本活动配置的商品与股指品种。
  5. 赠金性质：赠金总额为活动奖励额度，不等于已到账资金。剩余待释放额度不可直接提现、转赠、划转或用作保证金。合格交易将相应额度转为待发放返佣，实际到账后计为已发放。

二　参与与定档规则

  1. 累计起点：以首次成功入金到账时间为起点，连续计算24小时，不按自然日计算。
  2. 累计范围：窗口内多笔有效入金累计计算；恰好满24小时时及之后到账的入金不计入本次定档。有效入金以平台核验成功到账的本金记录为准，未到账、失败或虚假入金不计入。
  3. 档位确定：窗口结束后按24小时累计入金达到的最高档位锁定；后续入金不再改变本次活动档位。窗口内累计不足100 USD，不生成本次活动赠金额度。
  4. 窗口内交易：定档前的合格交易暂存，完成定档后按锁定档位统一补算，不按每次入金时的临时档位计算。

三　赠金计算与额度

  1. 赠金总额：24小时累计有效入金金额×200%，最高20,000 USD。例如累计入金1,000 USD，赠金总额为2,000 USD。
  2. 额度确认：24小时累计窗口结束并完成定档后，确定赠金总额；定档前的合格交易同步补算为待发放返佣。额度确认、返佣计算和实际到账是不同步骤。
  3. 剩余待释放：未计入返佣的赠金额度。待发放返佣已预占额度，后续交易不得重复使用；单笔返佣金额不得超过计算前的剩余待释放额度。
  4. 个人有效期：为90天，以页面显示的个人有效期截止时间为准。截止后不再因新增平仓成交产生返佣；截止前已确认的待发放返佣继续按发放流程处理，不等于剩余待释放额度可以无限期释放。

四　赠金释放与发放

  1. 有效交易：指定商品或股指的实际平仓成交，且对应持仓时间大于或等于1分钟。未成交、撤单、持仓不足1分钟及经核实的虚假交易不计入。
  2. 释放计算：本笔返佣金额＝本次平仓手数×该品种在用户档位下的每手返佣金额；计算结果超过剩余待释放额度时，以剩余额度为限。
  3. 分次平仓：每笔实际平仓成交分别按自己的平仓时间及手数计算，同一持仓可产生多笔计奖成交。
  4. 每日发放：完成定档后，每位用户每天汇总发放一次。定档前不发放；首次发放合并已补算且尚未发放的交易与当期应发交易。没有应发金额时不新增返佣记录；实际到账后才显示已发放。
  5. 查询记录：用户每日返佣记录关联对应交易；交易明细支持按平仓时间及平仓单号查询。

五　异常交易与活动资格处理

  1. 异常行为：重复账户参与、虚假入金、伪造成交或利用关联账户制造交易以重复获取奖励等行为，进入活动核查流程。
  2. 核查处理：平台根据核查结果按既有规则执行奖励停止发放或禁止参与，并保留相关记录。正常交易、正常提现或共享网络本身不直接作为违规结论。
  3. 异议反馈：对活动资格或返佣记录存在疑问，可通过平台客服提交用户ID及相关入金、成交记录进行核查。

六　其他说明

  1. 数据依据：以平台核验的实际到账记录、平仓成交记录和返佣发放记录为准；区块链入金按对应网络的有效确认规则处理。
  2. 活动叠加：是否与其他优惠同时使用，以相关活动页面明确公布的规则为准。
  3. 规则调整：活动规则或费率调整通过活动公告说明适用时间与范围；已锁定档位及已确认返佣不因页面更新自动重算。
  4. 时间及金额：原型统一使用UTC+8，金额使用USD，页面中的$表示USD；金额保留两位小数，手数保留实际精度。

当前原型按首次成功入金起算90天，并以每日09:00演示发放；90天起算点及正式发放时刻尚未最终确认。活动规则与原型统一以这两个参数的最终配置为准。
