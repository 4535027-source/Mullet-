万能验证码管理平台 原型

适用业务：手机号注册 / 手机号登录 / 登录后修改密码 / 忘记密码 · 验证码有效期统一 5 分钟

验证码列表

查询系统下发的验证码，包含系统短信验证码与管理员设置的万能验证码。

手机号 业务类型 验证码 来源 状态 生成时间 过期时间 剩余时间 操作

原型说明：数据保存在内存中，刷新页面后恢复初始示例数据。有效码超过 5 分钟未使用会自动转为「已失效」。

接口说明（供管理端联调）

POST /admin/sms-codes/universal

设置万能验证码。同一手机号 + 业务类型仅生效一个，重复设置覆盖旧码，并将该组合下未失效的短信验证码置为已失效。

请求参数

字段类型必填说明
phonestring是手机号，11 位数字
scenestring是业务类型，见下方枚举
codestring是6 位数字万能验证码

请求示例

{
  "phone": "13711112222",
  "scene": "RESET_PASSWORD",
  "code": "905317"
}

响应示例

{
  "code": 0,
  "message": "success",
  "data": {
    "id": 10086,
    "phone": "13711112222",
    "scene": "RESET_PASSWORD",
    "code": "905317",
    "source": "UNIVERSAL",
    "status": "VALID",
    "createdAt": "2026-11-05 10:00:00",
    "expireAt": "2026-11-05 10:05:00"
  }
}

GET /admin/sms-codes

分页查询系统下发的验证码列表（含短信验证码与万能码）。

查询参数

字段类型必填说明
phonestring否按手机号模糊查询
scenestring否业务类型，见下方枚举
sourcestring否来源：SYSTEM / UNIVERSAL
statusstring否状态：VALID / INVALID
pageint否页码，默认 1
pageSizeint否每页条数，默认 20

响应示例

{
  "code": 0,
  "message": "success",
  "data": {
    "total": 42,
    "list": [
      {
        "id": 10086,
        "phone": "13711112222",
        "scene": "RESET_PASSWORD",
        "code": "905317",
        "source": "UNIVERSAL",
        "status": "VALID",
        "createdAt": "2026-11-05 10:00:00",
        "expireAt": "2026-11-05 10:05:00"
      }
    ]
  }
}

枚举定义

枚举取值说明
sceneREGISTER手机号注册
LOGIN手机号登录
CHANGE_PASSWORD登录后修改密码
RESET_PASSWORD忘记密码
sourceSYSTEM系统短信下发
UNIVERSAL管理员设置的万能验证码
statusVALID有效（未过期、未被使用）
INVALID已失效（含已被使用、已过期、被万能码覆盖、管理员作废）

校验规则（C 端验证接口需支持）

  • 同一手机号 + 业务类型存在有效万能码时，仅万能码可通过校验，真实短信验证码一律不通过。
  • 万能码过期后（5 分钟），回退为按正常短信验证码校验。
  • 验证码校验通过后置为「已失效」，不可复用。

设置万能验证码

5 分钟（固定，与系统短信验证码一致）
覆盖规则：同一手机号 + 业务类型仅生效一个万能码；新万能码会覆盖旧万能码，且该手机号该业务的真实短信验证码立即失效（列表中标记为「已失效」）。
